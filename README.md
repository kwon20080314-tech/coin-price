# 암호화폐 시세 조회 페이지

비트코인, 이더리움의 이름·가격·등락률을 보여주는 간단한 웹 페이지임.
HTML, CSS, JavaScript만 사용함.

# 만든 기능

- 두 코인의 이름, 가격, 등락률을 화면에 표시함
- 등락률이 플러스면 빨간색, 마이너스면 파란색으로 표시함
- 가격에 천 단위 쉼표를 표시함 (95300000 → 95,300,000)
- (도전) 업비트 API에서 시세를 받아오는 것을 시도함 → 아래 "도전 기능" 참고

# 실행 방법

1. 폴더를 내려받음.
2. `index.html`을 브라우저로 엶. (필수 기능은 이것만으로 동작함)
3. 도전 기능(API 사용)은 VS Code의 Live Server 확장으로 실행함.
   `index.html` 우클릭 → "Open with Live Server"를 선택함.

# 파일 구성

- `index.html`: 화면 구조를 담당함
- `style.css`: 색상 (`.up` 빨강, `.down` 파랑)을 담당함
- `script.js`: 데이터를 화면에 표시하는 동작을 담당함

# 도전 기능 (업비트 API)

- 한 일: fetch로 API 데이터를 받아 콘솔에 출력하고, 응답 필드를 확인함
  (한글 이름 없음, 마켓 코드 사용, `signed_change_rate`는 비율 값임)
- 막힌 지점: 받아온 `data`를 기존 화면 표시 코드에 연결하는 부분임
  (`data`가 `.then` 안에서만 쓸 수 있다는 점을 확인함)
- 미완성: API 데이터를 화면에 표시하는 것까지는 완성하지 못함.
